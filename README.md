## Overview

**Agent Al – IQ Assistant** is a Flutter-based mobile application project focused on exploring intelligent assistant experiences and modern mobile application development.

The project brings together camera integration, machine-learning-based text recognition dependencies, state management, local persistence, and customizable UI themes.

It is developed with an emphasis on maintainable code, reusable components, and a smooth user experience.

## Technology Stack

| Technology | Purpose |
|---|---|
| Flutter | Cross-platform application development |
| Dart | Application programming language |
| Riverpod | State management |
| Google ML Kit | Text recognition |
| Camera | Camera integration |
| Shared Preferences | Local data persistence |
| Lottie | UI animations |

## Technical Highlights

- **State Management:** Riverpod for managing application state.
- **Camera Integration:** Camera initialization and device camera access.
- **Machine Learning:** Google ML Kit text recognition dependency.
- **Theme Management:** Light and dark theme configuration.
- **Local Persistence:** Shared Preferences initialization.
- **UI Experience:** Material-based interface and Lottie animations.
